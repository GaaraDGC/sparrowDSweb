1. 將示例影片放入 `assets/videos/`（例如把 `ref/GrapePromise_crf.mp4` 複製到 `assets/videos/GrapePromise_crf.mp4`）。
2. 將 poster 圖放入 `assets/images/`（例如 `gp-poster.jpg`），若未提供會使用 `assets/images/placeholder.svg`。
